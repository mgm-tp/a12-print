[#integration_dependencies]
= Dependencies

This section covers the dependencies necessary for integrating the Print Integration into an A12 Full Stack application.

== Prerequisite

[#prerequisite/client]
=== Client

Basic knowledge of using Client is necessary because the Print Integration heavily depends on Client.
See link:/docs/OVERALL/dev_tutorial_frontend_intro/index.html[Frontend tutorial] for further details.

For technical requirements, Print Integration shares the same configuration as Client.
If your application is capable of running with Client, then Print Integration can be used as well.

Please refer to the full-stack-project-template repository for an up-to-date template.

[#prerequisite/data-services]
=== Data Services

Basic knowledge of using Data Services is necessary because the Print Integration heavily depends on Data Services.

If your application is capable of running with Data Services, then Print Integration can be used as well.

Please refer to the full-stack-project-template repository for an up-to-date template.

== Backend Dependencies

For the usage with Maven, the following dependencies need to be added in the applications POM-file:

Maven plugin::

[source,bash]
----
<dependency>
    <groupId>com.mgmtp.a12.print</groupId>
    <artifactId>print-integration</artifactId>
    <version>{printEngineVersion}</version>
</dependency>
----

For the usage with Gradle, the following dependencies need to be added in the applications `build.gradle` file:

Gradle plugin::

[source,bash]
----
...
dependencies {
	...
	implementation("com.mgmtp.a12.print:print-integration:${printEngineVersion}")
	...
}
----

WARNING: It is assumed that the project is bootstrapped with <<prerequisite/data-services, Data Services>>.

== Frontend Dependencies

The necessary frontend dependency can be installed by the following command:

[source]
----
npm install @com.mgmtp.a12.print/print-integration
----

WARNING: It is assumed that the project is bootstrapped with <<prerequisite/client, Client>>.
