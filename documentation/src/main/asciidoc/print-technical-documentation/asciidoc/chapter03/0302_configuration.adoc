[#integration_configuration]
= Configuration

This section covers the configurations of the Print Integration.

== Backend Configuration

To activate printing functionality in the backend the Print Operation needs to be added to the allowlist in the Data Services configuration:

`mgmtp.a12.dataservices.jsonRpc.allowedOperations=PRINT`

In addition the Print integration needs to know the source paths for <<static_image_provider, static images>> and <<pdf_box_print_engine_config, fonts>>.
These can be defined by the following configurations from Data Services:

`mgmtp.a12.dataservices.resources.fonts.path`
`mgmtp.a12.dataservices.resources.static-images.path`

Apart from these points, no further action should be necessary to enable printing functionality in an A12 backend application.

But there are possible Print configuration parameters:

* `mgmtp.a12.print.engine.preCompilingEnabledForModels` = `*`
** Restricts pre-compiling to specified models while disabling all others. Setting the value to `*` permits all existing models.
* `mgmtp.a12.print.engine.timeZone` = `TimeZone.getTimeZone("UTC")`
** Allows you to define the time zone, which is needed for the localization of language specific content and dates.

== Frontend Configuration

There are two possible ways to activate printing functionality in the frontend of an A12 application.

=== Register Print Integration using `customSagas`

[source, typescript]
----
	config = ApplicationFactories.createApplicationSetup({
		...
		customSagas: [
			...PrintFactories.createSagas(),
		],
		...
	})
----

The `createSagas` method currently has two optional parameters:

* `showLoadingIndicatorDuringPrint`: A boolean which defines if a loading spinner should be shown during print execution
** Please make sure the `ProgressIndicator` is set up correctly so you can see the loading spinner.
* `validateAndSaveBeforePrint`: A boolean which defines if the form should be validated and saved before print execution

Both options are enabled by default.

=== Register Print Integration using Composable Factories (Experimental)

The same configuration possibilities can be registered in another way:

[source, typescript]
----
	const config: A12ApplicationConfig = {
		...
		print: {
			showLoadingIndicatorDuringPrint: true,
			validateAndSaveBeforePrint: true
		}
		...
	}
----

In addition, the Print feature needs to be registered with `withPrint`.
`withPrint` takes an application config and returns a new config with the Print feature.
Pass the final config to `createA12ApplicationSetup`.

[source, typescript]
----
	const configWithPrint = withPrint(config);
	...
	createA12ApplicationSetup(configWithPrint);
----


NOTE: Once the <<integration_dependencies, Dependencies>> have been properly set up and <<integration_configuration, configured>>
the models still need to be properly prepared (link:/docs/PRINT_ENGINE/print-modeling-documentation/index.html#print_model_usage[Print Model Usage]).
