= Expression [[Expression]]

The Expression element inserts the result of a Form Engine Expression into the resulting PDF.

Document Model:: Select a Document Model referenced in the <<SchemaTab, Schema Tab>>.
Content:: The Expression elements content is generated from the Expression _content_.
For more information regarding the expected syntax, please refer to the link:/docs/SME/sme-dm-ba-docs/index.html[Expression documentation].

The Expression Element can be hidden automatically if all referenced Fields are evaluated to an empty value or string. To enable this behavior, select the option `Hide this element if all nested entities are empty`.

Additionally, the Expression element is configurable using <<BorderProperties, Border Properties>> and <<TextProperties, Text Properties>>.
