= Schriftsatz [[Typesetting]]

Dieses Kapitel beschreibt, wie Sie den Schriftsatz von Text innerhalb der Print Engine anpassen können. Es richtet sich an Modeler, die mit der Print-Modellierung vertraut sind.
Der Schriftsatz steuert die Komposition und den Fluss von Text beim Drucken eines Dokuments.

== Konfiguration des Typesetting Model [[TypeSettingModel]]
Die Print Engine verfügt über ein dediziertes Typesetting Model, mit dem Sie anpassbare Regeln für die Gestaltung Ihres Textes hinzufügen können.

image::chapter05/TypeSetting_EditorScreenshot.png[Typesetting Editor,title="Typesetting Editor"]

Sie können ein neues Typesetting Model im SME Workspace erstellen und es durch Auswahl bearbeiten.
Pro Workspace können Sie mehrere Typesetting Models erstellen, bearbeiten und referenzieren.

Um Ihren Text zu beeinflussen, gehen Sie wie folgt vor:

1. Erstellen, bearbeiten und speichern Sie ein Typesetting Model.
2. Referenzieren Sie das Typesetting Model im <<SchemaTab,Schema Tab>> Ihres Print Model.
+
image::chapter05/Typesetting_ReferenceModel.png[Typesetting Model referenzieren,title="Typesetting Model referenzieren"]
+
3. Erstellen Sie einen Text Style und <<TypographySettings,referenzieren>> Sie das Typesetting Model.
+
image::chapter05/Typesetting_TextStyleReference.png[Text Style mit Typesetting Model,title="Text Style mit Typesetting Model"]
+
4. Sie können nun den benutzerdefinierten Text Style, den Sie erstellt haben, auf Ihre Print Model Elements anwenden.

=== Einstellungen für Zeilenumbruch-Verhinderung
Diese Einstellungen ermöglichen es Ihnen, Ausnahmen für die Silbentrennung und den Zeilenumbruch beim Drucken von Text mit der Print Engine zu definieren.

==== Zeichenfolgenregeln

Mit dieser Option können Sie bestimmte Wörter oder Zeichenfolgen definieren, die nicht getrennt werden sollen.

Um eine neue Zeichenfolge hinzuzufügen, klicken Sie auf die Schaltfläche btn:[Add]. Es wird eine neue Zeile in einer Tabelle hinzugefügt, in der Sie die gewünschte Zeichenfolge eingeben können.
Beachten Sie, dass nur Bindestriche (-) und alphabetische Zeichen erlaubt sind. Andere Zeichen wie Zahlen erzeugen eine Fehlermeldung und verhindern das Speichern des Modells.

Um eine Regel zu entfernen, klicken Sie auf die Schaltfläche rechts neben der Zeile und bestätigen Sie Ihre Auswahl im Dialog.

image::chapter05/Typesetting_CharacterSequence.png[Zeichenfolgenregeln,title="Zeichenfolgenregeln"]

==== Maßeinheitenregeln

Mit dieser Option können Sie Zeichenketten definieren, die als Maßeinheiten behandelt werden.
Wenn ihnen eine Zahl vorangestellt ist, wird kein Zeilenumbruch eingefügt. Das bedeutet, dass Zahl und Einheit zusammen auf derselben Zeile bleiben.

Um eine neue Maßeinheitenregel hinzuzufügen, klicken Sie auf die Schaltfläche btn:[Add]. Es wird eine neue Zeile in einer Tabelle hinzugefügt, in der Sie die gewünschte Einheit eingeben können.

Um eine Regel zu entfernen, klicken Sie auf die Schaltfläche rechts neben der Zeile und bestätigen Sie Ihre Auswahl im Dialog.

image::chapter05/Typesetting_NumberUnitRule.png[Maßeinheitenregeln,title="Maßeinheitenregeln"]

WARNING: Maßeinheitenregeln erlauben zwar eine breite Auswahl möglicher Symbole, diese werden jedoch möglicherweise von der Schriftart des gewählten Text Style nicht unterstützt. In diesem Fall kann das Print Model nicht gedruckt werden und zeigt einen Fehler in der Druckvorschau an.

==== Spezielle Musterregeln

Mit dieser Option können Sie einen Satz kuratierter Regeln anwenden, die für spezielle Anwendungsfälle entwickelt wurden.
Derzeit sind zwei spezielle Muster verfügbar:

* §{digit} Abs. {digit} – z. B. §3 Abs. 7 für Verweise auf deutsche Gesetzestexte
* {digit}({digit})({letter}) – z. B. 219(1)(a) für Verweise auf Dokumentabschnitte

Falls Sie andere spezielle Muster benötigen, die durch keine der vorhergehenden Optionen abgedeckt werden können, wenden Sie sich bitte an das Print Engine-Team, um eine neue spezielle Musterregel implementieren zu lassen.

image::chapter05/Typesetting_SpecialPatternRule.png[Spezielle Musterregeln,title="Spezielle Musterregeln"]

=== Einstellungen für Schusterjungen und Hurenkinder

Im Schriftsatz sind „Schusterjunge" (Orphan) und „Hurenkind" (Widow) Begriffe, die definieren, wie Text am Anfang oder Ende einer Seite im Hinblick auf den visuellen Textfluss behandelt wird.
Eine korrekte Handhabung von Schusterjungen und Hurenkindern ergibt professionell wirkende Dokumente und verhindert, dass isolierte Zeilen den Lesefluss stören.
Da die Definitionen variieren, legt das Typesetting Model sie wie folgt fest:

* Widows: Wie viele isolierte Zeilen am Anfang einer Seite erlaubt sind (Standard: 2)
* Orphans: Wie viele isolierte Zeilen am Ende einer Seite erlaubt sind (Standard: 2)

Diese Einstellungen ermöglichen es dem Modeler, benutzerdefinierte Grenzwerte für Orphans und Widows für seine Texte festzulegen.

image::chapter05/Typesetting_OrphanWidow2.png[Beispiel für Widow und Orphan (Standardgrenzwert),title="Beispiel für Widow und Orphan (Standardgrenzwert)."]

=== Roles

Die Roles-Tabelle ermöglicht es Ihnen, die erlaubten Roles für das Typesetting Model zu definieren.

Sie können Roles aus dem Workspace auswählen, indem Sie auf btn:[Add] klicken und eine Option aus dem Dropdown-Menü wählen. Roles können gelöscht werden, indem Sie auf die rote Schaltfläche in der Zeile klicken und Ihre Auswahl bestätigen.
