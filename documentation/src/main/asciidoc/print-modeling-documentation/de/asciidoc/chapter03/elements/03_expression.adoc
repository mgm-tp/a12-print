= Expression [[Expression]]

Das Expression-Element fügt das Ergebnis eines Form-Engine-Ausdrucks in das resultierende PDF ein.

Document Model:: Wählen Sie ein Document Model aus, das im <<SchemaTab, Schema Tab>> referenziert ist.
Content:: Der Inhalt des Expression-Elements wird aus dem Expression-_content_ erzeugt.
Weitere Informationen zur erwarteten Syntax finden Sie in der link:/docs/SME/sme-dm-ba-docs/index.html[Expression-Dokumentation].

Das Expression-Element kann automatisch ausgeblendet werden, wenn alle referenzierten Fields einen leeren Wert oder String ergeben. Um dieses Verhalten zu aktivieren, wählen Sie die Option `Hide this element if all nested entities are empty`.

Darüber hinaus lässt sich das Expression-Element über <<BorderProperties, Border Properties>> und <<TextProperties, Text Properties>> konfigurieren.
