= Switch [[Switch]]

Das Switch-Element ist ein Container-Element, ähnlich wie <<Area, Area>> und <<BoundingBox, BoundingBox>>. Es bietet die Möglichkeit, Elemente in einem bestimmten Bereich zu gruppieren.

Dieser erweiterte Container steuert dynamisch die Sichtbarkeit der enthaltenen <<Area, Area>>-Elemente auf Basis festgelegter Preconditions.

Um auf die <<SwitchCases, Switch Cases>> zuzugreifen, bewegen Sie den Mauszeiger über die Area und klicken Sie auf die angezeigte Schaltfläche „Edit" in der oberen rechten Ecke der Area.

[CAUTION]
====
Es ist nicht erlaubt, <<BorderProperties, Border Properties>> auf dem Switch und einen DataContext auf der <<Area, Area>> Case zu setzen.
====

== Switch Cases [[SwitchCases]]

Preconditions und zugehörige <<Area, Area>>-Elemente werden durch Klicken auf „Add" hinzugefügt.
Diese Preconditions werden als <<Computations>> in der Syntax der link:/docs/KERNEL/kernel-documentation-ba-en/index.html[Kernel Language] geschrieben.

Verlassen Sie die Switch-Cases-Ansicht, indem Sie auf die gewünschte Ebene in der Breadcrumb-Navigation oben links klicken.

Precondition:: Wenn eine Precondition zu _True_ ausgewertet wird, wird das zugehörige Area-Element an derselben Switch-Position sichtbar.
+
Wenn die Precondition zu _False_ ausgewertet wird, wird das Area-Element ausgeblendet.
+
Wenn alle Preconditions zu _False_ ausgewertet werden, wird auch der Switch ausgeblendet.
+
[NOTE]
====
Es ist möglich, dass mehrere Cases gleichzeitig sichtbar sind.
====

Elements:: Für jede Precondition wird eine <<Area, Area>> mit den Abmessungen des Switch erstellt.
Weitere Details zur Bearbeitung finden Sie beim <<Area, Area>>-Element.
