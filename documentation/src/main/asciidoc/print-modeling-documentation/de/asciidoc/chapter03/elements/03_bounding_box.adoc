= Bounding Box [[BoundingBox]]

Das Bounding-Box-Element ermöglicht es, Elemente in einem bestimmten Bereich zu gruppieren.
Die Bounding Box funktioniert analog zur Area, mit dem Unterschied, dass sie nicht mit ihrem Inhalt wächst und keine Möglichkeit bietet, einen Datenkontext festzulegen.

Die Eigenschaften des Bounding-Box-Elements werden durch seine <<BorderProperties, Border Properties>> bestimmt.

Um die <<BoundingBoxStage, Bounding Box Stage View>> aufzurufen, bewegen Sie den Mauszeiger über die Bounding Box und klicken Sie auf die eingeblendete Schaltfläche „Edit" in der oberen rechten Ecke der Bounding Box.

== Bounding Box Stage View [[BoundingBoxStage]]
Die Bounding Box Stage View funktioniert ähnlich wie die <<EditorStage, Editor Stage>>.

Die wesentlichen Unterschiede zwischen diesen Editor Stage Views sind:

* Die Bounding Box Stage View hat die Abmessungen der zugehörigen Bounding Box.
* Die Bounding Box Stage View zeigt die Ränder der zugehörigen Bounding Box an.

Elemente innerhalb einer Bounding Box werden relativ zur oberen linken Ecke der Bounding Box positioniert.

Verlassen Sie die Bounding Box Stage View, indem Sie in der Breadcrumb-Navigation oben links auf die gewünschte Ebene klicken.

[NOTE]
====
* Die Positionierung der Elemente innerhalb einer Bounding Box wird durch den Rand der Bounding Box nicht beeinflusst. Daher können sich Elemente und der Rand der Bounding Box überlappen.
* Die Höhenberechnung und Positionierung der Elemente innerhalb der Bounding Box erfolgt unabhängig von Elementen außerhalb der Bounding Box.
====
