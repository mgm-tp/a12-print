= Table Layout [[TableLayout]]

Das Table Layout Element fügt eine statische Tabelle in das resultierende PDF-Dokument ein und bietet damit ein statisches Layout für seine Inhalte.

[ACCESSIBILITY_HINT]
====
icon:universal-access[] *Barrierefreiheitshinweis*

Dieses Element wird derzeit nicht empfohlen, wenn das resultierende PDF-Dokument Barrierefreiheitsstandards entsprechen soll.
Es wird stets als Tabelle interpretiert, auch wenn es in Ihrer Modellierung anders verwendet wird.

Stattdessen sollten Sie Text-Elemente manuell in der Editor Stage anordnen.
====

Number of Rows:: Die Anzahl der Zeilen in der resultierenden Tabelle.
Number of Columns:: Die Anzahl der Spalten in der resultierenden Tabelle.

Row Properties::
Index::: Eine Zahl im Bereich von 1 bis zur definierten Zeilenanzahl, die die durch diese Eigenschaftengruppe angesprochene Zeile identifiziert.
Minimal Row Height::: Definiert die Mindesthöhe einer Zeile in Millimetern.
Wenn kein Wert gesetzt ist, wird der Standardwert von 10 mm verwendet.
Siehe <<InputSource>> für weitere Details.
Column Properties::
Index::: Eine Zahl im Bereich von 1 bis zur definierten Spaltenanzahl, die die durch diese Eigenschaftengruppe angesprochene Spalte identifiziert.
Column Width::: Definiert die Breite einer Spalte in Prozent relativ zur Breite des Table Layout Elements.
Vertical Alignment::: Definiert die vertikale Ausrichtung der Spalteninhalte.
Mögliche Werte sind:
+
* Top
* Middle
* Bottom

Das Table Layout Element ist über <<BorderProperties, Border Properties>> konfigurierbar.

== Table Layout Cells [[TableLayoutCells]]
Nach der Modellierung der Zeilen und Spalten im Table Layout können Print Model Elements in jeder Zelle hinzugefügt, bearbeitet und gelöscht werden. Bewegen Sie dazu den Mauszeiger über die gewünschte Zelle im Table Layout in der Editor Stage.

Um ein Element hinzuzufügen, klicken Sie auf die Schaltfläche pass:["+"] in einer leeren Zelle. Daraufhin öffnet sich ein Popup, in dem Sie den hinzuzufügenden Elementtyp auswählen können.

[NOTE]
====
Derzeit ist der einzige unterstützte Typ das <<Text, Text>>-Element.
====

Um ein vorhandenes Zell-Element zu bearbeiten, bewegen Sie den Mauszeiger über die gewünschte Zelle im Table Layout und klicken Sie auf die Schaltfläche „Edit".

Um den Inhalt einer Zelle zu entfernen, bewegen Sie den Mauszeiger über die Zelle und klicken Sie auf die Schaltfläche „Delete".
