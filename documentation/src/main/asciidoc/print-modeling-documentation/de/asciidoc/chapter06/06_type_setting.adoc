= Typografie [[Typesetting]]

Dieses Kapitel beschreibt, wie Sie den Textsatz in der Print Engine anpassen können. Es richtet sich an Modeler, die mit der Print-Modellierung vertraut sind.
Der Textsatz steuert die Komposition und den Textfluss beim Drucken eines Dokuments.

== Konfiguration des Typesetting-Modells [[TypeSettingModel]]
Die Print Engine verfügt über ein eigenes Typesetting-Modell, mit dem Sie anpassbare Regeln für den Textsatz definieren können.

image::chapter05/TypeSetting_EditorScreenshot.png[Typesetting Editor,title="Typesetting-Editor"]

Sie können ein neues Typesetting-Modell im SME Workspace erstellen und es durch Auswahl bearbeiten.
Pro Workspace können Sie mehrere Typesetting-Modelle erstellen, bearbeiten und referenzieren.

Um Ihren Text zu beeinflussen, gehen Sie wie folgt vor:

1. Erstellen, bearbeiten und speichern Sie ein Typesetting-Modell.
2. Referenzieren Sie das Typesetting-Modell im <<SchemaTab,Schema Tab>> Ihres Print Model.
+
image::chapter05/Typesetting_ReferenceModel.png[Referenzierung des Typesetting-Modells,title="Referenzierung des Typesetting-Modells"]
+
3. Erstellen Sie einen Text Style und <<TypographySettings,referenzieren>> Sie das Typesetting-Modell.
+
image::chapter05/Typesetting_TextStyleReference.png[Text Style mit Typesetting-Modell,title="Text Style mit Typesetting-Modell"]
+
4. Sie können nun den erstellten benutzerdefinierten Text Style auf Ihre Print Model Elements anwenden.

=== Einstellungen für Zeilenumbruchverhinderung
Diese Einstellungen ermöglichen es Ihnen, Ausnahmen für Silbentrennung und Zeilenumbruch beim Drucken von Text mit der Print Engine zu definieren.

==== Zeichenfolgenregeln

Mit dieser Option können Sie bestimmte Wörter oder Zeichenfolgen definieren, die nicht getrennt werden sollen.

Um eine neue Zeichenfolge hinzuzufügen, klicken Sie auf die Schaltfläche btn:[Add]. Eine neue Zeile wird in einer Tabelle hinzugefügt, in der Sie die gewünschte Zeichenfolge eingeben können.
Beachten Sie, dass nur Bindestriche (-) und Buchstaben erlaubt sind. Andere Zeichen wie Zahlen erzeugen eine Fehlermeldung und verhindern das Speichern des Modells.

Um eine Regel zu entfernen, klicken Sie auf die Schaltfläche rechts neben der Zeile und bestätigen Sie Ihre Auswahl im Dialog.

image::chapter05/Typesetting_CharacterSequence.png[Zeichenfolgenregeln,title="Zeichenfolgenregeln"]

==== Maßeinheitsregeln

Mit dieser Option können Sie Zeichenketten definieren, die als Maßeinheiten behandelt werden.
Wenn ihnen eine Zahl vorangestellt ist, wird kein Zeilenumbruch eingefügt. Die Zahl und die Einheit bleiben somit auf derselben Zeile.

Um eine neue Maßeinheitsregel hinzuzufügen, klicken Sie auf die Schaltfläche btn:[Add]. Eine neue Zeile wird in einer Tabelle hinzugefügt, in der Sie die gewünschte Einheit eingeben können.

Um eine Regel zu entfernen, klicken Sie auf die Schaltfläche rechts neben der Zeile und bestätigen Sie Ihre Auswahl im Dialog.

image::chapter05/Typesetting_NumberUnitRule.png[Maßeinheitsregeln,title="Maßeinheitsregeln"]

WARNING: Maßeinheitsregeln erlauben zwar die Verwendung einer großen Auswahl möglicher Symbole, diese werden jedoch möglicherweise nicht von der Schriftart des ausgewählten Text Style unterstützt. In diesem Fall kann das Print Model nicht gedruckt werden und zeigt in der Druckvorschau einen Fehler an.

==== Spezielle Musterregeln

Mit dieser Option können Sie einen Satz kuratierter Regeln anwenden, die für spezielle Anwendungsfälle konzipiert wurden.
Derzeit stehen zwei spezielle Muster zur Verfügung:

* §{digit} Abs. {digit} – z. B. §3 Abs. 7 für die Referenzierung deutscher Gesetzestexte
* {digit}({digit})({letter}) – z. B. 219(1)(a) für die Referenzierung von Dokumentabschnitten

Falls Sie andere spezielle Muster benötigen, die durch keine der vorhergehenden Optionen abgedeckt werden können, wenden Sie sich bitte an das Print Engine-Team, um eine neue spezielle Musterregel implementieren zu lassen.

image::chapter05/Typesetting_SpecialPatternRule.png[Spezielle Musterregeln,title="Spezielle Musterregeln"]

=== Einstellungen für Schusterjungen und Hurenkinder

Im Textsatz bezeichnen „Schusterjunge" (Orphan) und „Hurenkind" (Widow) Begriffe, die festlegen, wie Text am Anfang oder Ende einer Seite im Hinblick auf den visuellen Textfluss behandelt wird.
Eine korrekte Handhabung von Schusterjungen und Hurenkindern führt zu professionell aussehenden Dokumenten und verhindert, dass isolierte Zeilen den Lesefluss stören.
Da die Definitionen variieren, legt das Typesetting-Modell sie wie folgt fest:

* Hurenkinder (Widows): Wie viele isolierte Zeilen am Anfang einer Seite erlaubt sind (Standard: 2)
* Schusterjungen (Orphans): Wie viele isolierte Zeilen am Ende einer Seite erlaubt sind (Standard: 2)

Diese Einstellungen ermöglichen es dem Modeler, individuelle Grenzwerte für Schusterjungen und Hurenkinder für seine Texte zu definieren.

image::chapter05/Typesetting_OrphanWidowSetting.png[Einstellungen für Hurenkinder und Schusterjungen,title="Einstellungen für Hurenkinder und Schusterjungen."]

image::chapter05/Typesetting_OrphanWidow2.png[Beispiel für Hurenkinder und Schusterjungen (Standardgrenzwert),title="Beispiel für Hurenkinder und Schusterjungen (Standardgrenzwert)."]

image::chapter05/Typesetting_OrphanWidow5.png[Beispiel für Schusterjungen und Hurenkinder mit Grenzwert 5,title="Beispiel für Schusterjungen und Hurenkinder mit Grenzwert 5."]

=== Roles

Die Roles-Tabelle ermöglicht es Ihnen, die zulässigen Roles für das Typesetting-Modell zu definieren.

Sie können Roles aus dem Workspace auswählen, indem Sie auf btn:[Add] klicken und eine Option aus dem Dropdown-Menü auswählen. Roles können durch Klicken auf die rote Schaltfläche in der Zeile und Bestätigung Ihrer Auswahl gelöscht werden.
